## L1. Link flit and PHY sizing

Link flit: 1024 data + 128 NoC header + 64 link header + 32 CRC = 1248 bits (156 B). Payload efficiency of a symmetric write stream (16 data flits + 1 ack flit per 2 KiB): 0.772.

| link | unit | raw per direction | units per die | payload per die per direction |
|---|---|---|---|---|
| D2D | sub-link = 2 lanes x 1 flit/cycle = 2 UCIe-A x64 modules at 32 GT/s (91% used) | 468 GB/s | 4 sub-links, 8 modules | 1.45 TB/s (frozen: 1.40) |
| C2C | port = 6 lanes x 200 Gb/s | 150 GB/s | 8 ports, 48 lanes | 0.93 TB/s (frozen: 0.80) |
